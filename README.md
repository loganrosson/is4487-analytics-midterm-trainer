# IS 4487 – Business Analytics Midterm Trainer

A study app for a business analytics (pandas / data science) midterm. One self-contained file; Python 3.8+ with Tkinter.

## Features
- Practice midterm, concept drills by week, code-reading questions, business cases, and essays with model answers
- **Exam simulation** with a 60-minute clock and essay questions
- **Code Lab (F2):** runs each question's pandas code *one statement at a time* on real lab data and shows what changed — rows, columns, dtypes, missing values, new variables, printed output, and charts — with an optional "predict first" mode
- Detailed feedback on missed questions, flashcards, and live cheat sheets
- Every question is tagged by source

## Run it
```bash
python IS4487_Midterm_Trainer.py
```
The quizzes need nothing else. For the Code Lab and live cheat sheets:
```bash
pip install -r requirements.txt
```
